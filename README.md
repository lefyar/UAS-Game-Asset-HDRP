# UAS Game Asset HDRP Semester 4

An outdoor scene study built with the High Definition Render Pipeline. Explore the environment and its water assets in the Scene view.

## Open in Unity

Install Unity **6000.0.73f1** through Unity Hub. Choose **Add project from disk**, select the repository root, and let Unity restore the packages and import the assets.

Open [OutdoorsScene](Assets/OutdoorsScene.unity) from the Project window. Inspect the artwork and layout in the Scene view.
